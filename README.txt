Crystal Deals — сайт + сервер (без внешних зависимостей, нужен Node.js 18 или новее)

ЗАПУСК
  ADMIN_PASSWORD=ваш_пароль node server.js
  Сайт: http://localhost:3000     Менеджер: http://localhost:3000/admin.html

ПЕРЕМЕННЫЕ
  PORT              порт (по умолчанию 3000)
  ADMIN_PASSWORD    пароль менеджера (без него админка выключена)
  TON_WALLET        адрес для пополнений TON (по умолчанию ваш)
  TONCENTER_KEY     ключ toncenter.com (бесплатный, снимает лимиты запросов)
  COINGECKO_KEY     необязательно: бесплатный demo-ключ coingecko.com, если CoinGecko ограничивает запросы (курсы тогда берутся и с бирж)
  TEST_BALANCE      сколько RUB дарить новым аккаунтам (для тестов, например 10000; для боя не задавайте)
  DATA_FILE         путь к файлу данных (по умолчанию data.json рядом с server.js)

ЧТО УМЕЕТ СЕРВЕР
  Регистрация и вход (пароли хешируются scrypt), сделки по ссылке между разными устройствами,
  чат с фото, оплата с баланса, передача товара со скриншотом, подтверждение, вывод заявкой,
  обменник, пополнение TON (сервер сам раз в 30 секунд ищет платёж по комментарию и сумме,
  каждая транзакция засчитывается один раз), админка менеджера (выводы, споры, ручное пополнение).

ПЕРЕД БОЕВЫМ ЗАПУСКОМ
  1. Поставьте за HTTPS (Caddy или nginx + Let's Encrypt). Запускайте через pm2 или systemd.
  2. Данные лежат в data.json: делайте резервные копии. Для большой нагрузки перенесите в PostgreSQL.
  3. Курсы валют живые: сервер раз в минуту берёт их с CoinGecko (запасной вариант: Binance + open.er-api).
     Если курс не обновлялся 30 минут, оплата сделок и обмен временно блокируются, чтобы не работать по старой цене.
  4. Проверка TON идёт через публичный toncenter. Для надёжности используйте ключ TONCENTER_KEY.
  5. Хранение чужих денег может требовать лицензий и правил (KYC/AML) в вашей юрисдикции. Проверьте это.

ФОТО И ОТЗЫВЫ
  Фото из чатов и аватары сохраняются файлами в папке uploads рядом с файлом данных (DATA_FILE).
  На Render держите DATA_FILE и uploads на подключённом диске (например DATA_FILE=/data/data.json).
  Отзывы оставляют только участники завершённых сделок (по одному на сделку), дата ставится сервером.
  Новый отзыв сначала попадает в админку со статусом «На проверке» и появляется на сайте только после того, как админ нажмёт «Одобрить».
  Админ может отклонить отзыв, скрыть/показать одобренный и ответить на него. Добавлять отзывы вручную нельзя.

НОВОЕ В ЭТОЙ ВЕРСИИ
  Ранги: Бронза (0), Серебро (5), Золото (15), Платина (40), Алмаз (100 успешных сделок). Пороги: RANKS в server.js.
  Профили: нажмите на аватар участника в сделке, откроется его профиль (ранг, сделки, рейтинг, отзывы).
  Редактирование: ник (раз в 14 дней, сделки и отзывы переезжают на новый ник), о себе, аватар.
  Реквизиты проверяются: адрес кошелька по сети (TON, TRC20, ERC20, BEP20, BTC, SOL, с контрольной суммой),
  карта по алгоритму Луна, телефон для СБП, юзернейм для Stars (подойдёт любой).
  Типы товара: NFT (ссылка), NFT юзернейм, NFT номер, Аккаунт и Разное (любой текст, ссылки, цифры).
  Цена сделки в валюте продавца фиксируется в момент оплаты покупателем, а не в момент создания.
  Отзывы появляются только после настоящих сделок.

ВАЛЮТА СДЕЛКИ И АДМИНКА
  Валюта сделки зависит от реквизитов продавца: Stars -> звёзды (целое число), крипто-кошелёк -> монета сети
  (TON -> TON или USDT, TRC20/BEP20 -> USDT, ERC20 -> USDT или ETH, BTC -> BTC, SOL -> SOL), карта -> валюта страны
  (РФ рубль, Украина гривна, Казахстан тенге, Беларусь белорусский рубль). Продавец получает деньги в валюте сделки.
  Админка (/admin.html): пополнение и списание баланса (ник любого регистра, запятая в сумме допустима, выбор валюты),
  история операций, создание сделки для пользователей (продавец, покупатель необязательно).
